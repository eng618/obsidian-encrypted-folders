# Desktop test checklist

Use this note as a quick checklist while testing on desktop.

- [ ] Confirm the folder can be encrypted from the context menu.
- [ ] Confirm unlocking restores plaintext files.
- [ ] Confirm edits inside the folder refresh the folder inactivity timer.
- [ ] Confirm 5-minute inactivity locks the folder again.
- [ ] Confirm putting Obsidian in the background locks the folder immediately.
- [ ] Confirm the locked state syncs back to the other device.
- [ ] Confirm unlocking after sync does not produce missing-file or partial-sync errors.
