# Desktop test checklist

Use this note as a quick checklist while testing on desktop.

- [x] Confirm the folder can be encrypted from the context menu.
- [x] Confirm unlocking restores plaintext files.
- [x] Confirm edits inside the folder refresh the folder inactivity timer.
- [x] Confirm 5-minute inactivity locks the folder again.
- [x] Confirm putting Obsidian in the background locks the folder immediately.
- [x] Confirm the locked state syncs back to the other device.
- [x] Confirm unlocking after sync does not produce missing-file or partial-sync errors.
