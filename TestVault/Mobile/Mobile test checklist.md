# Mobile test checklist

Use this note as a quick checklist while testing on mobile.

- [ ] Confirm the folder unlocks successfully on mobile.
- [ ] Confirm edits on mobile sync back to desktop after re-locking.
- [ ] Confirm 5-minute inactivity locks only this folder.
- [ ] Confirm backgrounding the app locks unlocked folders quickly.
- [ ] Confirm the desktop client receives a consistent locked state.
- [ ] Confirm unlocking after sync does not fail with partial payload errors.
