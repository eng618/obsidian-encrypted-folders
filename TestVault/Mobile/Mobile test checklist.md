# Mobile test checklist

Use this note as a quick checklist while testing on mobile.

- [x] Confirm the folder unlocks successfully on mobile.
- [x] Confirm edits on mobile sync back to desktop after re-locking.
- [x] Confirm 5-minute inactivity locks only this folder.
- [x] Confirm backgrounding the app locks unlocked folders quickly.
- [x] Confirm the desktop client receives a consistent locked state.
- [x] Confirm unlocking after sync does not fail with partial payload errors.
